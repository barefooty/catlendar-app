# 🐱 Catlendar — 可憐上班族的貓貓日曆

一個單檔 HTML 的個人工作站：任務、日曆、追蹤、便利貼、記帳、習慣打卡、番茄鐘……
全部在瀏覽器裡運作，**資料只存在你自己的裝置裡**，這個網站不會收集、也看不到任何人的資料。

## 📲 手機安裝

1. 手機開啟：https://barefooty.github.io/catlendar-app/
2. iPhone：Safari 底部「分享」→「**加入主畫面**」；Android：Chrome 右上「⋮」→「加到主畫面」
3. 建議到 ⚙️ 設定開啟「☁️ 雲端同步」當資料保險（設定頁有三步驟教學）

## 💻 電腦使用

直接開同一個網址就能用。

## 🔒 資料與隱私

- 所有資料存在你自己瀏覽器裡（localStorage），不會上傳到這個網站
- 跨裝置同步靠你自己 Google 帳號的同步小幫手，資料存在你自己的雲端硬碟
